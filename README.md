## 🎯 功能全景

### 1️⃣ 双算法引擎
- **等额本息**：每月还款额固定，前期利息占比高，适合现金流稳定的人。
- **等额本金**：每月本金固定、月供逐月递减，总利息更少，适合前期还款能力强的人。
- 内置公式切换无需刷新，一键对比两种方式的总利息差额和月供曲线。

### 2️⃣ 总利息 vs 本金 甜甜圈
圆环直观展示「你借的钱里，有多少最终变成了利息」，圆心实时显示利息占比百分数。

### 3️⃣ 每期还款构成面积图
- 本金（蓝，逐期上升）/ 利息（橙，逐期下降）双色堆叠面积图
- **悬浮提示**：任意月份显示该期 月供 / 本金 / 利息 / 剩余本金，附引导线与高亮点
- **提前还款红色虚线**标记在时间轴上
- 支持展开完整还款明细表（期数、月供、本金、利息、剩余本金、备注）

### 4️⃣ ⚡ 提前还款模拟
- 输入：提前还款金额 + 第几年后 + 处理方式
- 两种处理方式：
  - **缩短期限**（月供不变，年限缩短）
  - **减少月供**（期限不变，每月轻松些）
- 输出：节省利息金额与比例、新期限/新月供、新总还款对比

### 5️⃣ 零息贷款节省测算
一键回答「如果这笔钱零利息，我能省多少」，把利息支出换算为你能多攒下的本金。

### 6️⃣ 等额本息 vs 等额本金 同条件对比表
月供、总利息、总还款、利息占比四项并列，自动生成结论（省多少利息、首月多还多少）。

### 7️⃣ 利率敏感性柱状图
当前利率 ±0.5% / ±1% 五个档位的总利息柱状对比，配文字结论：利率每升 0.5%，月供和总利息各增加多少。

### 8️⃣ 50/30/20 法则覆盖能力
- 预算条：需要 50% / 想要 30% / 储蓄 20% 三色显示
- 两条红线结论：**月供 ≤ 月收入 30%**（房贷经验线）、**月供 ≤ 50% 需要桶上限**
- 收入留空时，自动倒推「覆盖这笔月供至少需要多少收入」

### 9️⃣ 交互细节
- 本金 / 利率 / 期限**滑杆与输入框双向联动**，另有 10万/50万/100万…快捷档位
- 关键数字**滚动动画**，等宽表格数字对齐
- **URL 参数分享**：参数写入地址栏 `#`，刷新不丢；一键复制分享链接
- 桌面端输入卡**吸顶**，移动端自适应单列布局

## 🔗 URL 分享参数

把 `#` 后的参数发给朋友即可复现你的计算场景：

| 参数 | 含义 | 示例 |
|---|---|---|
| `principal` | 贷款本金（元） | `1000000` |
| `rate` | 年利率（%） | `4.2` |
| `years` | 期限（年） | `30` |
| `income` | 月收入（元，用于 50/30/20） | `20000` |
| `ppAmt` | 提前还款金额（元） | `200000` |
| `ppYear` | 第几年后提前还款 | `5` |
| `method` | 还款方式 | `emi`（等额本息）/ `ep`（等额本金） |
| `ppMode` | 提前还款处理 | `shorten`（缩短期限）/ `reduce`（减少月供） |

## 🔢 计算口径与正确性

**等额本息月供**：`EMI = P·r·(1+r)^n / ((1+r)^n − 1)`，其中 `r = 年利率/12`，`n = 期数`；利率为 0 时退化为 `P/n`。

**等额本金**：每期归还本金 `P/n`，利息 = 剩余本金 × `r`，月供逐期递减。

**提前还款**：在第 `k` 期开始时一次性冲抵本金，随后按所选模式重算剩余计划；所有还款计算集中在 `buildSchedule(P, rate, years, method, prepay)` 一处，无重复实现。

**已验证基准值**（Node 复算 + 浏览器实渲染双重验证，100 万 / 4.2% / 30 年）：
- 等额本息月供 **¥4,890.17**，总利息 **¥760,462**，期末余额归零 ✅
- 等额本金首月 **¥6,277.78** → 末月 **¥2,787.50** ✅
- 零息月供 ¥2,777.78 ✅
- 提前 20 万 @ 第 5 年（缩短期限）：省息 **¥279,219**，缩短 **97 期** ✅

## 🧩 技术架构

- **单文件自包含**：CSS + HTML + JavaScript 全部内联于 `index.html`（约 35KB），离线可用
- **零依赖**：不引入 React / Chart.js / D3 / 任何 CDN，图表 100% 手写 SVG
- **集中式计算**：`buildSchedule()` 返回完整还款计划 `{sched, n0, actualTerm, totalInt, totalPay, ...}`，展示层只读不重算
- **文件结构**：

```
loan-calculator/
├── index.html          # 主程序（全部内容）
├── README.md           # 本文档
├── PRIVACY-AUDIT.md    # 隐私审计报告
├── LICENSE             # MIT
├── .gitignore
└── .nojekyll           # 跳过 Jekyll，GitHub Pages 原样托管
```
